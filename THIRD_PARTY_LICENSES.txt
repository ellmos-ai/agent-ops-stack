1. EXECUTIVE SUMMARY & COMPLIANCE ASSURANCE
================================================================================

agent-ops-stack is engineered as a declarative, manifest-driven composition layer
for multi-agent CLI coordination (Claude Code, OpenAI Codex, Google Antigravity /
Gemini, Moonshot Kimi). The repository itself contains zero mandatory runtime
dependencies beyond the standard Python runtime and POSIX shell utilities.

All direct, optional, and development dependencies utilized in agent-ops-stack
are distributed under strictly permissive open-source licenses (MIT, Apache-2.0,
PSFL-2.0). There are zero copyleft, GPL, or AGPL dependencies in the core
composition or packaging harness, ensuring maximum flexibility for enterprise
engineering teams, multi-agent frameworks, and autonomous developer workflows.
Canonical copyright and ecosystem attributions are formally preserved in the
root NOTICE file.

3. ZERO-COPYLEFT ISOLATION GUARANTEE & RUNASINVOKER CERTIFICATION
================================================================================

1. Zero-Copyleft Isolation Guarantee:
   All core runtime and tooling dependencies operate strictly under permissive
   open-source licenses (MIT, Apache-2.0, PSFL-2.0). The codebase, packaging
   specifications, and installer harness are completely free of GPL, AGPL,
   LGPL, SSPL, or reciprocal copyleft obligations.

2. Unprivileged Execution (RunAsInvoker):
   agent-ops-stack enforces unprivileged user-mode execution under INV-USER-02.
   All manifest validation, shell installation, and module coordination operate
   strictly within non-elevated user context without requiring administrative
   elevation, root privileges, or daemon background services.

3. Fail-Closed Security & Concurrency Defense:
   Under INV-LOCK-03 and INV-ROUT-04, any mutating action checks lock state
   and routing tickets. Conflicting operations fail closed immediately,
   preventing split-brain states or destructive Git index corruption across
   concurrent AI agent sessions.

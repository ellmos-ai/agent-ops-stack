1. EXECUTIVE SUMMARY & VALUE PROPOSITION
--------------------------------------------------------------------------------
agent-ops-stack provides the canonical local-first operational coordination harness
for multi-agent CLI coding workflows (Claude Code, OpenAI Codex, Google Antigravity /
Gemini, Moonshot Kimi). It composes seven focused, modular pillars into a cohesive
operational layer:
  - dev-bricks/ticket-master (ticket-routing & issue dispatch)
  - dev-bricks/lock-master (file locking & exclusive edit boundaries)
  - dev-bricks/sync-master (cross-machine slot file synchronization)
  - ellmos-ai/build-your-users-mind (decision-avatar for operator absence)
  - ellmos-ai/skills (standardized reusable skill packs)
  - ellmos-ai/ellmos-controlcenter-mcp (MCP server discovery & control plane)
  - ellmos-ai/ellmos-homebase-mcp (state, memory facade, and task facade)

Rather than forcing developers into monolithic, opinionated runtime loops,
agent-ops-stack operates declaratively via agent-ops.manifest.json (schema
ellmos-stack-manifest-v1) and a lightweight shell installer (install.sh). It solves
concurrency collisions, untracked bugs, operator absence ambiguity, and tool discovery
without any external network egress, telemetry, or administrative privilege elevation.

2. TARGET AUDIENCE & STAKEHOLDER PERSONAS
--------------------------------------------------------------------------------
1. Autonomous AI Agent Engineers & Platform Architects:
   - Operating multiple concurrent coding agents (Claude Code, Codex, Antigravity, Kimi)
     on local workspaces.
   - Require reliable file locking (lock-master) to eliminate destructive merge races
     and conflicting write operations.
2. Multi-Device & Cross-Machine Developers:
   - Alternating between workstations, laptops, and remote servers.
   - Depend on sync-master slot gating to synchronize project states without split-brain
     conflicts or broken Git indices.
3. Enterprise Tooling, Safety & Governance Compliance Officers:
   - Mandating 100% offline, local-first operations with zero external network egress.
   - Require unprivileged user-mode execution (RunAsInvoker), deterministic manifest
     blueprints, and auditable third-party license inventories.
4. Open-Source AI Tool Builders & MCP Ecosystem Integrators:
   - Developing modular MCP tools, skill packs, and automation agents.
   - Rely on ellmos-controlcenter-mcp and ellmos-homebase-mcp for standardized discovery,
     tool bundling, and shared task coordination.

4. COMPETITIVE POSITIONING & COMPARISON
--------------------------------------------------------------------------------
- vs. Cloud LLMOps & Telemetry SaaS (AgentOps.ai, LangSmith, Helicone):
  Cloud platforms mandate outbound network egress, remote telemetry collection, and
  external credential storage. agent-ops-stack is 100% local-first and zero-egress,
  keeping all project source code, file locks, and decision logs strictly on localhost.
- vs. Monolithic Agent Frameworks (AutoGen, CrewAI, LangGraph):
  Heavy frameworks impose tight execution loops, proprietary messaging buses, and
  complex runtime dependencies. agent-ops-stack is a decoupled, manifest-driven
  composition layer providing shared conventions (locking, tickets, avatars) to any
  independent CLI tool or agent.
- vs. Ad-hoc Shell Scripts & Uncoordinated Worktrees:
  Ad-hoc scripts lack formal concurrency models and shared state. agent-ops-stack
  enforces fail-closed locking, structured ticket scoring, and empirical user avatars
  to prevent architectural drift when the human operator is away.
